# HƯỚNG DẪN THÊM ẢNH NHÀ RẠP SƠN NỤ

Thư mục hình ảnh được chia làm 2 thư mục riêng biệt để bạn **không cần phải đổi tên ảnh**:

1. **`rap-dam-cuoi/`**:
   - Thả toàn bộ ảnh rạp đám cưới, rạp tư gia biệt thự, rạp ngoài trời vào thư mục này.
   - Hỗ trợ mọi định dạng: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg` (kể cả viết hoa `.JPG`, `.PNG`).
   - Tên ảnh tùy ý (ví dụ: `IMG_001.jpg`, `damcuoi_khach.jpg`, `1.jpg`...), hệ thống sẽ tự động hiển thị vào mục "Rạp Đám Cưới".

2. **`rap-an-hoi/`**:
   - Thả toàn bộ ảnh rạp ăn hỏi, lễ gia tiên, rạp đính hôn vào thư mục này.
   - Hỗ trợ mọi định dạng: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`.
   - Tên ảnh tùy ý (ví dụ: `anhoi_01.jpg`, `DSC0192.jpg`...), hệ thống sẽ tự động hiển thị vào mục "Rạp Ăn Hỏi".
